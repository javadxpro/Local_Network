# 🖥️ Local_Network

یک پلتفرم آفلاین و آنلاین برای بازی‌کردن، اشتراک‌گذاری ویدیو و چت با دوستان در یک شبکه محلی.

🇮🇷 پروژه ایرانی | ✅ آزادانه و رایگان

---

## 🎯 ویژگی‌ها

- ✨ **چت محلی:** پیام‌رسانی فوری با کاربران متصل
- 🎬 **اشتراک‌گذاری ویدیو:** آپلود و نمایش ویدیوها در شبکه
- 👨‍💼 **مدیریت کاربران:** پنل ادمین برای کنترل دسترسی
- 🔒 **احراز هویت امن:** ثبت‌نام و ورود محفوظ
- 📱 **رابط‌کاربری مدرن:** طراحی ریسپانسیو و تاریک
- ⚡ **بدون وابستگی پیچیده:** فقط Python استاندارد

---

## 🚀 نحوه نصب و اجرا

### پیش‌نیازها

- **Python 3.7+** یا بالاتر
- یک سیستم عامل (Windows, macOS, Linux)

### مراحل نصب

#### 1️⃣ مخزن را کلون کنید

```bash
git clone https://github.com/javadxpro/Local_Network.git
cd Local_Network
```

#### 2️⃣ سرور را اجرا کنید

```bash
python server.py
```

#### 3️⃣ مرورگر خود را باز کنید

```
http://localhost:5555
```

یا از IP دستگاه برای دسترسی از سایر دستگاه‌ها:

```
http://YOUR_IP:5555
```

## 📋 راهنمای استفاده

### 🔐 ثبت‌نام و ورود

1. صفحه ورود را ببینید
2. اگر حساب ندارید، بر روی "ثبت نام کن" کلیک کنید
3. نام کاربری (حداقل ۳ کاراکتر) و رمز (حداقل ۴ کاراکتر) وارد کنید
4. بعد از ثبت‌نام، وارد شوید

### 🎬 اشتراک‌گذاری ویدیو

1. به تب **آپلود فایل** بروید
2. ویدیوی خود را انتخاب کنید (MP4, MKV, AVI, WebM)
3. منتظر تکمیل آپلود بمانید
4. ویدیو در تب **ویدیوها** نمایش داده می‌شود

### 💬 چت

1. به تب **گپ و گفت** بروید
2. پیام خود را بنویسید و ارسال کنید
3. پیام‌های تمام کاربران به‌صورت real-time ظاهر می‌شوند

### 👨‍💼 مدیریت کاربران (فقط ادمین)

1. دکمه **ادمین** را در گوشه سمت راست بالا کلیک کنید
2. لیست کاربران را ببینید
3. کاربران را حذف کنید (فقط کاربران عادی)
